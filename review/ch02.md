# 第2章 照合の記録

| # | 記述 | 根拠 | 判定 |
|---|---|---|---|
| 1 | コア仕様は LE と Classic の両方を1つの文書で定義している | Core v7.0 の構成（Vol 2 が BR/EDR、Vol 6 が LE） | 一致 |
| 2 | コア仕様は数千ページ | Core v7.0 の分量 | 一致 |
| 3 | Immediate Alert Service は Alert Level を持ち、書き込まれた値に応じて警告する | IAS v1.0 §3.1、§4.1 | 一致 |
| 4 | Find Me Profile は探す側と探される側の2つの役を定義する | FMP v1.0 §2.1（Find Me Locator と Find Me Target） | 一致 |
| 5 | 独自のサービスを定義してよい | Vol 3 Part G §2.5（128ビットの UUID） | 一致 |
| 6 | Mesh は別のプロトコル仕様 | Mesh Protocol（コア仕様の外） | 一致 |
| 7 | 心拍サービスは `0x180D` | Assigned Numbers（16ビットの UUID） | 一致 |
| 8 | アドバタイズのデータ項目は Core Specification Supplement で定義 | CSS Part A | 一致 |
