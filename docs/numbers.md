# 付録A 数字の早見表

本書に出てきた数字をまとめました。詳しくは各章を見てください。どの数字も Core v7.0 で確かめています。LE 編の表の「原本」の列に印のないものは、本書がコア仕様や関連する仕様書に基づいて補ったものか、原本と値が違うものです。Classic の数字は[ページの後半](#classic-の数字)にあります。
