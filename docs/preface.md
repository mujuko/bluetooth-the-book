# はじめに

イヤホン、スマートウォッチ、紛失防止タグ、体重計。私たちの身の回りには Bluetooth で話す機械があふれています。しかし「設定画面でペアリングすると、なぜかつながるもの」という以上のことは、あまり知られていません。

この本は、そのしくみを**電波の性質から順に、筋道を立てて**説明する教科書です。読み終えるころには、次のような疑問に自分の言葉で答えられるようになっているはずです。

- コイン電池1個で、なぜ1年も動くのか
- Wi-Fi や電子レンジと同じ周波数を使っているのに、なぜ通信できるのか
- スマホのアプリは、心拍計の「心拍数」をどうやって読み取っているのか
- 左右のイヤホンは、なぜ音がずれないのか
- 電波で「距離」をはかる、とはどういうことか

## 想定している読者

- 理科が得意な高校生
- 数学は苦手だけれど、理系の大学生
- 生物系を専攻してからソフトウェアの仕事に就いた SE

必要なのは、四則計算と「ビットとバイト」くらいです。式はなるべく言葉で書き、三角関数や微積分は使いません。逆に、話を簡単にするためにウソをつくこともしません。少し込み入った話は、込み入っていると断ったうえで説明します。

## 原本との関係

この本は、Bluetooth 規格の管理団体 Bluetooth SIG が公開している解説文書 [The Bluetooth® Low Energy Primer](https://www.bluetooth.com/bluetooth-le-primer/)（2024年10月の v1.3.0。以下「原本」）を骨組みの参考にしています。

ただし**翻訳ではありません**。原本は製品開発者に向けて、スタックの下の層から順に説明しています。本書では読者層に合わせて説明の順番を組み替え、文章、たとえ話、図、確認問題はすべて書き下ろしました。原本の図や文章は転載していません。

本書は非公式の教材で、Bluetooth SIG とは関係がありません。正確な定義が必要なときは、必ず原本と公式の仕様書にあたってください。

細かすぎる話は本文からカットしました。その代わり、カットした話は各章の終わりに「原本にはこんな話も」という枠で、どの節に何が書いてあるかを一言ずつ残しています。全体の対応は[付録C](./primer-map)にまとめました。

## 最低限の約束ごと

本文で使う記法をまとめておきます。

**ビットとバイト**　ビットは 0 か 1 の1桁です。8ビットで1バイトになります。仕様書では1バイトのことを「オクテット（octet）」と呼びますが、同じものと思ってかまいません。

**16進数**　`0x` で始まる数は16進数です。0〜9 と A〜F の16種類で1桁を表し、2桁でちょうど1バイトになります。たとえば `0x48` は 4×16 + 8 = 72 です。

**速さの単位**　1 Mb/s は1秒に100万ビットです。1バイトは8ビットなので、1 Mb/s はだいたい1秒に125キロバイトです。

**時間の単位**　1ミリ秒（ms）は1000分の1秒、1マイクロ秒（µs）は100万分の1秒です。無線の話ではマイクロ秒がよく出てきます。

**扱わないもの**　昔ながらの Bluetooth（Bluetooth Classic）の詳しいしくみと、数万台の機器をつなぐ Bluetooth Mesh は本書の範囲外です。原本も Mesh は扱っていません。

それでは始めましょう。
