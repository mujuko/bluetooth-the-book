第4章で、Bluetooth の電波に共通する基礎を見ました。この章では、LE の物理層に固有の話を見ていきます。

## 19.1 40本のチャネル

LE は 2400〜2483.5 MHz の範囲を、幅 2 MHz の**チャネル**に区切ります。全部で40本です。Classic の79本（第7章）より粗い区切り方です。

図で黄色に塗った3本（37, 38, 39番）は、第21章で扱うアドバタイズ専用のチャネルです。**わざと離れた3か所に配置されている**ことに注目してください。Wi-Fi でよく使われるチャネルの隙間や端に当たる位置なので、どれか1本が邪魔されても、残りが生き残る可能性が高くなります。残りの37本は汎用で、おもにデータの通信に使います。

## 19.2 PHY の種類

物理層の通信方式の組み合わせを **PHY**（ファイ）と呼びます。LE でよく使われるのは次の4つです。

| | LE 1M | LE 2M | LE Coded（S=2） | LE Coded（S=8） |
|---|---|---|---|---|
| シンボルの速さ | 1 Msym/s | 2 Msym/s | 1 Msym/s | 1 Msym/s |
| プロトコルの速さ | 1 Mb/s | 2 Mb/s | 500 kb/s | 125 kb/s |
| アプリが使える速さ（約） | 800 kb/s | 1400 kb/s | 400 kb/s | 100 kb/s |
| 届く距離（LE 1M を1として、約） | 1 | 0.8 | 2 | 4 |
| 誤り訂正 | なし | なし | あり | あり |
| 対応 | 必須 | 任意 | 任意 | 任意 |

**LE 1M** は基本の方式で、すべての LE 機器が対応しなければなりません。変調は第4章の GFSK です。

**LE 2M** はシンボルを2倍の速さで送ります。距離は少し短くなりますが、同じデータを半分の時間で送れるので、そのぶん無線を早く止められて電力の節約にもなります。チャネルの幅が 2 MHz あるので、Classic のようにシンボルの速さを 1 Msym/s に据え置く必要がありません（第7章）。

**LE Coded** は、速さを犠牲にして遠くまで届かせる方式です。ひとつのビットを複数のシンボルで冗長に表し（S=2 なら2シンボル、S=8 なら8シンボル）、誤り訂正符号（FEC）も加えます。受信側は多少のシンボルが化けても元のビットを推定できます。

::: analogy 騒がしい場所で話す
遠くの人に騒がしい場所で何かを伝えるとき、私たちはゆっくり、同じことを繰り返して話します。これが LE Coded です。逆に、すぐ近くの人とは早口で話せます。これが LE 2M です。
:::

なぜゆっくり送ると遠くまで届くのでしょうか。送信の強さが同じなら、1ビットに長い時間をかけるほど、そのビットに注ぎ込むエネルギーが増えるからです。雑音の中でも信号を見分けやすくなります。

::: bio
Coded PHY の冗長性は、遺伝暗号の縮重に少し似ています。コドンの3文字目が変異してもアミノ酸が変わらないことが多いように、冗長性のおかげで、一部が化けても意味が失われません。もちろん、代償として同じ情報を運ぶのに多くの「文字」が必要になります。
:::

::: extra 距離と感度の関係
原本の PHY の比較表で、S=8 の距離が 1M の4倍になっているのは、コア仕様が求める受信感度が約 12 dB よい（−70 dBm に対して −82 dBm）ことと対応しています。第4章で見たとおり、理想的な空間では距離が2倍になるごとに 6 dB 弱まるので、12 dB は距離にして4倍です。
:::

ほかに **LE 2M 2BT** という PHY もありますが、これは第25章の Channel Sounding 専用で、普通のデータ通信には使いません。

もうひとつ、Core 7.0 で **LE HDT**（High Data Throughput）という任意の PHY が加わりました。GFSK のように周波数を上下させるのではなく、波の位相や振幅を何段階にも変えて、1シンボルに2〜4ビットを詰め込みます。Coded とは逆向きの工夫で、考え方は Classic の EDR（第7章）に近いものです。これに誤り訂正の符号を組み合わせ、2、3、4、6、7.5 Mb/s の5段階から速さを選べます。ただし使えるのは接続したあとの通信だけで、アドバタイズには使えません。これで LE の PHY は、1M、2M、2M 2BT、Coded、HDT の5つになりました。

::: extra ASK という別の変調
第25章で扱う Channel Sounding の一部では、電波を「出す／出さない」で 1 と 0 を表す ASK（Amplitude Shift Keying）という方式も使います。普通のデータ通信は GFSK です。
:::

## まとめ

- LE は 2.4 GHz 帯を幅 2 MHz の40チャネルに分けて使う。3本がアドバタイズ用、37本が汎用
- アドバタイズ用を3本に絞ったので、探す側は聞くだけで相手を見つけられる
- PHY には、速い 2M、基本の 1M、遠くまで届く Coded がある。ビットあたりの時間とエネルギーのトレードオフである
- Core 7.0 の HDT は、1シンボルに複数のビットを詰め込んで最大 7.5 Mb/s を出す

## 確認問題

1. アドバタイズ用の3本のチャネルが、わざと離れた場所に置かれているのはなぜでしょうか。
2. LE 2M にすると距離は短くなるのに、電力の節約になることがあるのはなぜでしょうか。
3. LE Coded の S=8 で 100 ビットを送ると、何マイクロ秒かかるでしょうか（誤り訂正の分は考えなくてかまいません）。

::: details 答え
1. Wi-Fi などの混信で1本が使えなくなっても、ほかの2本が生き残る可能性を高くするためです。
2. 同じデータを半分の時間で送れるので、無線回路を動かす時間が短くなるからです。
3. 1ビットに 8 µs かかるので、100 × 8 = 800 µs です。
:::
