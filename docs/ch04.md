# 第4章 電波の基礎

::: goal
- 電波の周波数と波長の関係を計算で示せる
- 2.4 GHz 帯を、Classic と LE がそれぞれどう区切って使っているかを説明できる
- 0 と 1 を電波に乗せる方法（周波数偏移変調）を図で説明できる
- dB と dBm を使った簡単な計算ができる
:::

ここで、スタックの一番下の**物理層**に共通する話をまとめておきます。物理層の仕事は、デジタルの 0 と 1 を電波に変えること、そして受け取った電波から 0 と 1 を取り出すことです。Classic と LE は細部こそ違いますが、土台になる考え方は同じです。

## 4.1 電波は波である

電波は光の仲間で、空間を光速で伝わる波です。波には次の関係があります。

<div class="formula">波の速さ（光速）＝ 周波数 × 波長</div>

周波数は1秒に振動する回数で、単位はヘルツ（Hz）です。Bluetooth が使う 2.4 GHz は、1秒に24億回振動する波です。波長を計算してみましょう。

<div class="formula">30万 km/秒 ÷ 24億回/秒 ＝ 0.125 m ＝ 12.5 cm</div>

Bluetooth の電波は、1回の振動で約 12.5 cm 進みます。この数字は第25章の距離測定で再び登場します。

::: extra 2.4 GHz と水
2.4 GHz 付近の電波は水に吸収されやすいという性質があり、電子レンジも同じ帯域を使っています。人間の体は水分が多いので、体をはさむと電波はかなり弱まります。スマホをお尻のポケットに入れるとヘッドホンの音が途切れやすくなることがあるのは、このためです。
:::

## 4.2 2.4 GHz 帯とチャネル

Bluetooth は、Classic も LE も 2400〜2483.5 MHz の範囲を使います。ここは **ISM 帯**と呼ばれ、多くの国で免許なしで使えます。その代わり、Wi-Fi や電子レンジなど多くの機器が同じ帯域をひしめき合って使っています。

この範囲を、決まった幅の**チャネル**に区切って使います。区切り方は2つの方式で違います。

## 4.3 0 と 1 を電波に乗せる

ただ同じ周波数の電波を出し続けても、情報は伝わりません。情報を伝えるには、波の性質をデータに応じて変化させます。これを**変調**といいます。ラジオの AM は波の振幅（大きさ）を、FM は周波数を変化させて音を乗せています。

Bluetooth が基本に使うのは、FM に近い **GFSK**（Gaussian Frequency Shift Keying）です。Classic の BR も LE も、この方式を使います。やっていることは単純です。チャネルの中心周波数を基準に、

- 周波数を少し**上げる** → 1
- 周波数を少し**下げる** → 0

とします。ずらす量は、Classic の BR で少なくとも 115 kHz、LE の標準の方式で少なくとも 185 kHz と決められています。

名前の頭についている「ガウス（Gaussian）」は、周波数の切り替えを滑らかにするフィルタのことです。急激に周波数を変えると、その瞬間に余計な周波数成分が生まれ、隣のチャネルにまで電波がはみ出してしまいます。滑らかに変化させることで、これを抑えています。

GFSK のほかに、波の**位相**を変えて情報を乗せる方式もあります。Classic の EDR（第7章）や、LE の HDT（第19章）がそうです。

## 4.4 シンボルとビット

変調された波の、1つの単位を**シンボル**と呼びます。図4-2 でいえば、周波数が上か下かを判定する1区間です。物理層の速さは、ビットではなくシンボルの数で「1 Msym/s（毎秒100万シンボル）」のように表します。Classic はどのモードでも 1 Msym/s、LE には 1 Msym/s と 2 Msym/s があります。

なぜわざわざ言葉を分けるのでしょうか。GFSK では1シンボルがちょうど1ビットに対応するので、ふだんは区別しなくても困りません。ところが、Classic の EDR や LE の HDT は、1シンボルに2〜4ビットを詰め込みます。逆に LE の Coded（第19章）は、1ビットを何シンボルも使って送ります。そのときに区別が必要になります。

## 4.5 同時には話せない

Bluetooth の無線は、送信と受信を同時に行えません。これを**半二重**といいます。トランシーバーと同じで、話している間は聞けないわけです。

そこで「ある時間は A が話し、次の時間は B が話す」と時間で区切って交互に通信します。これを**時分割複信（TDD）**といいます。切り替えが十分に速いので、上の層からは同時に双方向で通信しているように見えます。区切り方は、Classic では 625 µs のスロット（第6章）、LE では接続イベント（第22章）です。

## 4.6 電波の強さとデシベル

無線の話をするには、**デシベル（dB）**に慣れておく必要があります。怖がらなくて大丈夫です。電波の強さは何桁にもわたって変わるので、掛け算を足し算に変えて楽をするための単位です。覚えるのは次の3つだけです。

| dB の変化 | 電力の変化 |
|---|---|
| ＋3 dB | 約2倍 |
| ＋10 dB | 10倍 |
| −10 dB | 10分の1 |

たとえば ＋13 dB は 10 + 3 なので、10倍の2倍で約20倍です。

**dBm** は 1 mW を基準にした絶対的な強さです。0 dBm が 1 mW で、＋20 dBm は 100 mW、−20 dBm は 0.01 mW になります。LE のコア仕様は、最大出力の設定値が −20 dBm から ＋20 dBm の間にあることを求めています。ただし実際に許される出力は、国ごとの法規で決まります。

電波は距離の2乗に反比例して弱まります（**逆2乗の法則**）。距離が2倍になると強さは4分の1、つまり −6 dB です。

::: extra 届く距離を見積もってみる
2.4 GHz の電波は、障害物のない理想的な空間でも 1 m 進むと約 40 dB 弱まります。送信が 0 dBm なら、受信の強さは次のようになります。

| 距離 | 1 m | 2 m | 4 m | 8 m | 16 m | 32 m | 64 m |
|---|---|---|---|---|---|---|---|
| 受信の強さ | −40 dBm | −46 | −52 | −58 | −64 | −70 | −76 |

受信機が聞き取れる限界（次に説明する受信感度）を −95 dBm とすれば、理論上は数百 m 届くことになります。実際には壁や人の体、床や天井での反射があるので、はるかに短くなります。カタログの到達距離をそのまま信じないようにしましょう。
:::

**受信感度**は、受信機がどこまで弱い電波を聞き取れるかを表す値です。ただし「聞き取れる」の基準が必要なので、ビットが化ける割合（**ビット誤り率、BER**）で定義します。Classic でも LE でも、BER 0.1%、つまり1000ビットに1ビット間違える状況が基準になっています。どちらの仕様も、基本の方式で −70 dBm 以下の感度を求めています。

受信機は受け取った電波の強さを **RSSI**（Received Signal Strength Indicator）という値で報告できます。RSSI は「近いと強く、遠いと弱い」のでだいたいの距離の目安にはなりますが、反射や体の影響で大きくぶれるので、正確な距離は分かりません。この問題への本格的な答えが第25章に登場します。

::: extra 日本で電波を出すには
無線機器を日本国内で使うには、原則として「技適マーク」のついた機器である必要があります。海外の開発ボードをそのまま使うときは、電波法上の扱いを確認してください。原本も、法規は地域ごとに確認するよう注意を促しています。
:::

## まとめ

- Bluetooth は 2.4 GHz 帯を使う。Classic は 1 MHz 幅の79チャネル、LE は 2 MHz 幅の40チャネルに区切る
- どちらもチャネルを次々に変える周波数ホッピングで、混信に強くしている
- GFSK は、周波数を上下にずらして 1 と 0 を表す。Classic の BR と LE の基本の方式で使われる
- 送受信は同時にできないので、時間で区切って交互に話す（TDD）
- ＋3 dB で約2倍、＋10 dB で10倍。距離が2倍になると −6 dB

## 確認問題

1. 周波数 2480 MHz の波長は何 cm でしょうか。光速は秒速30万 km とします。
2. LE の1つのチャネルの幅には、Classic のチャネルが何本分入るでしょうか。
3. 送信出力を 0 dBm から ＋10 dBm に上げると、理想的な空間で届く距離は何倍になるでしょうか。

::: details 答え
1. 300,000,000 ÷ 2,480,000,000 ≒ 0.121 m、約 12.1 cm です。
2. LE は 2 MHz、Classic は 1 MHz なので、2本分です。
3. 距離を2倍にするたびに 6 dB 必要です。10 dB は 6 dB と 4 dB に分けられ、4 dB は約1.6倍の距離にあたるので、約3.2倍です（電力が10倍なら、距離は 10 の平方根倍、と考えても同じ答えになります）。
:::
