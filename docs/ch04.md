# 第4章 電波と物理層

::: goal
- 2.4 GHz 帯と40本のチャネルの配置を説明できる
- 0 と 1 を電波に乗せる方法（周波数偏移変調）を図で説明できる
- PHY の種類ごとの「速さと届く距離のトレードオフ」を理由つきで説明できる
- dB と dBm を使った簡単な計算ができる
:::

ここからスタックの一番下、**物理層**に入ります。物理層の仕事は、デジタルの 0 と 1 を電波に変えること、そして受け取った電波から 0 と 1 を取り出すことです。

## 4.1 電波は波である

電波は光の仲間で、空間を光速で伝わる波です。波には次の関係があります。

<div class="formula">波の速さ（光速）＝ 周波数 × 波長</div>

周波数は1秒に振動する回数で、単位はヘルツ（Hz）です。Bluetooth が使う 2.4 GHz は、1秒に24億回振動する波です。波長を計算してみましょう。

<div class="formula">30万 km/秒 ÷ 24億回/秒 ＝ 0.125 m ＝ 12.5 cm</div>

Bluetooth の電波は、1回の振動で約 12.5 cm 進みます。この数字は第10章の距離測定で再び登場します。

::: extra 2.4 GHz と水
2.4 GHz 付近の電波は水に吸収されやすいという性質があり、電子レンジも同じ帯域を使っています。人間の体は水分が多いので、体をはさむと電波はかなり弱まります。スマホをお尻のポケットに入れると腕時計との通信が不安定になることがあるのは、このためです。
:::

## 4.2 40本のチャネル

Bluetooth LE は 2400〜2483.5 MHz の範囲を使います。ここは **ISM 帯**と呼ばれ、多くの国で免許なしで使えます。その代わり、Wi-Fi や電子レンジなど多くの機器が同じ帯域をひしめき合って使っています。

LE はこの範囲を幅 2 MHz の**チャネル**に区切ります。全部で40本です。

## 4.3 0 と 1 を電波に乗せる

ただ同じ周波数の電波を出し続けても、情報は伝わりません。情報を伝えるには、波の性質をデータに応じて変化させます。これを**変調**といいます。ラジオの AM は波の振幅（大きさ）を、FM は周波数を変化させて音を乗せています。

Bluetooth LE が使うのは、FM に近い **GFSK**（Gaussian Frequency Shift Keying）です。やっていることは単純です。チャネルの中心周波数を基準に、

- 周波数を少し**上げる** → 1
- 周波数を少し**下げる** → 0

とします。ずらす量は、標準の方式で少なくとも 185 kHz です。

名前の頭についている「ガウス（Gaussian）」は、周波数の切り替えを滑らかにするフィルタのことです。急激に周波数を変えると、その瞬間に余計な周波数成分が生まれ、隣のチャネルにまで電波がはみ出してしまいます。滑らかに変化させることで、これを抑えています。

::: extra ASK という別の変調
第10章で扱う Channel Sounding の一部では、電波を「出す／出さない」で 1 と 0 を表す ASK（Amplitude Shift Keying）という方式も使います。普通のデータ通信は GFSK です。
:::

## 4.4 シンボルとビット

変調された波の、1つの単位を**シンボル**と呼びます。図4-2 でいえば、周波数が上か下かを判定する1区間です。物理層の速さは、ビットではなくシンボルの数で「1 Msym/s（毎秒100万シンボル）」のように表します。

なぜわざわざ言葉を分けるのでしょうか。GFSK では1シンボルがちょうど1ビットに対応するので、ふだんは区別しなくても困りません。しかし次節の Coded 方式では、1ビットを何シンボルも使って送ります。そのときに区別が必要になります。

## 4.5 4種類の PHY

物理層の通信方式の組み合わせを **PHY**（ファイ）と呼びます。代表的なものは次のとおりです。

| | LE 1M | LE 2M | LE Coded（S=2） | LE Coded（S=8） |
|---|---|---|---|---|
| シンボルの速さ | 1 Msym/s | 2 Msym/s | 1 Msym/s | 1 Msym/s |
| プロトコルの速さ | 1 Mb/s | 2 Mb/s | 500 kb/s | 125 kb/s |
| アプリが使える速さ（約） | 800 kb/s | 1400 kb/s | 400 kb/s | 100 kb/s |
| 届く距離（LE 1M を1として、約） | 1 | 0.8 | 2 | 4 |
| 誤り訂正 | なし | なし | あり | あり |
| 対応 | 必須 | 任意 | 任意 | 任意 |

**LE 1M** は基本の方式で、すべての LE 機器が対応しなければなりません。

**LE 2M** はシンボルを2倍の速さで送ります。距離は少し短くなりますが、同じデータを半分の時間で送れるので、そのぶん無線を早く止められて電力の節約にもなります。

**LE Coded** は、速さを犠牲にして遠くまで届かせる方式です。ひとつのビットを複数のシンボルで冗長に表し（S=2 なら2シンボル、S=8 なら8シンボル）、誤り訂正符号（FEC）も加えます。受信側は多少のシンボルが化けても元のビットを推定できます。

::: analogy 騒がしい場所で話す
遠くの人に騒がしい場所で何かを伝えるとき、私たちはゆっくり、同じことを繰り返して話します。これが LE Coded です。逆に、すぐ近くの人とは早口で話せます。これが LE 2M です。
:::

なぜゆっくり送ると遠くまで届くのでしょうか。送信の強さが同じなら、1ビットに長い時間をかけるほど、そのビットに注ぎ込むエネルギーが増えるからです。雑音の中でも信号を見分けやすくなります。

::: bio
Coded PHY の冗長性は、遺伝暗号の縮重に少し似ています。コドンの3文字目が変異してもアミノ酸が変わらないことが多いように、冗長性のおかげで、一部が化けても意味が失われません。もちろん、代償として同じ情報を運ぶのに多くの「文字」が必要になります。
:::

ほかに **LE 2M 2BT** という PHY もありますが、これは第10章の Channel Sounding 専用で、普通のデータ通信には使いません。

## 4.6 同時には話せない

LE の無線は、送信と受信を同時に行えません。これを**半二重**といいます。トランシーバーと同じで、話している間は聞けないわけです。

そこで「ある時間は A が話し、次の時間は B が話す」と時間で区切って交互に通信します。これを**時分割複信（TDD）**といいます。切り替えが十分に速いので、上の層からは同時に双方向で通信しているように見えます。

## 4.7 電波の強さとデシベル

無線の話をするには、**デシベル（dB）**に慣れておく必要があります。怖がらなくて大丈夫です。電波の強さは何桁にもわたって変わるので、掛け算を足し算に変えて楽をするための単位です。覚えるのは次の3つだけです。

| dB の変化 | 電力の変化 |
|---|---|
| ＋3 dB | 約2倍 |
| ＋10 dB | 10倍 |
| −10 dB | 10分の1 |

たとえば ＋13 dB は 10 + 3 なので、10倍の2倍で約20倍です。

**dBm** は 1 mW を基準にした絶対的な強さです。0 dBm が 1 mW で、＋20 dBm は 100 mW、−20 dBm は 0.01 mW になります。コア仕様は、最大出力の設定値が −20 dBm から ＋20 dBm の間にあることを求めています。ただし実際に許される出力は、国ごとの法規で決まります。

電波は距離の2乗に反比例して弱まります（**逆2乗の法則**）。距離が2倍になると強さは4分の1、つまり −6 dB です。

::: extra 届く距離を見積もってみる
2.4 GHz の電波は、障害物のない理想的な空間でも 1 m 進むと約 40 dB 弱まります。送信が 0 dBm なら、受信の強さは次のようになります。

| 距離 | 1 m | 2 m | 4 m | 8 m | 16 m | 32 m | 64 m |
|---|---|---|---|---|---|---|---|
| 受信の強さ | −40 dBm | −46 | −52 | −58 | −64 | −70 | −76 |

受信機が聞き取れる限界（次に説明する受信感度）を −95 dBm とすれば、理論上は数百 m 届くことになります。実際には壁や人の体、床や天井での反射があるので、はるかに短くなります。カタログの到達距離をそのまま信じないようにしましょう。

原本の PHY の比較表で、S=8 の距離が 1M の4倍になっているのは、感度が約 12 dB よくなることと対応しています。
:::

**受信感度**は、受信機がどこまで弱い電波を聞き取れるかを表す値です。ただし「聞き取れる」の基準が必要なので、ビットが化ける割合（**ビット誤り率、BER**）で定義します。LE の話では BER 0.1%、つまり1000ビットに1ビット間違える状況がよく基準になります。

受信機は受け取った電波の強さを **RSSI**（Received Signal Strength Indicator）という値で報告できます。RSSI は「近いと強く、遠いと弱い」のでだいたいの距離の目安にはなりますが、反射や体の影響で大きくぶれるので、正確な距離は分かりません。この問題への本格的な答えが第10章に登場します。

::: extra 日本で電波を出すには
無線機器を日本国内で使うには、原則として「技適マーク」のついた機器である必要があります。海外の開発ボードをそのまま使うときは、電波法上の扱いを確認してください。原本も、法規は地域ごとに確認するよう注意を促しています。
:::

## まとめ

- LE は 2.4 GHz 帯を幅 2 MHz の40チャネルに分けて使う。3本がアドバタイズ用、37本が汎用
- GFSK は、周波数を上下にずらして 1 と 0 を表す
- PHY には、速い 2M、基本の 1M、遠くまで届く Coded がある。ビットあたりの時間とエネルギーのトレードオフである
- ＋3 dB で約2倍、＋10 dB で10倍。距離が2倍になると −6 dB

## 確認問題

1. 周波数 2480 MHz（39番チャネル）の波長は何 cm でしょうか。光速は秒速30万 km とします。
2. LE 2M にすると距離は短くなるのに、電力の節約になることがあるのはなぜでしょうか。
3. 送信出力を 0 dBm から ＋10 dBm に上げると、理想的な空間で届く距離は何倍になるでしょうか。

::: details 答え
1. 300,000,000 ÷ 2,480,000,000 ≒ 0.121 m、約 12.1 cm です。
2. 同じデータを半分の時間で送れるので、無線回路を動かす時間が短くなるからです。
3. 距離を2倍にするたびに 6 dB 必要です。10 dB は 6 dB と 4 dB に分けられ、4 dB は約1.6倍の距離にあたるので、約3.2倍です（電力が10倍なら、距離は 10 の平方根倍、と考えても同じ答えになります）。
:::
