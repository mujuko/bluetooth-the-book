# 付録C 原本との対応表

**扱い**の見方は次のとおりです。

- ◎：本書でも説明した
- ○：要点を説明した（細部は原本へ）
- △：触れるだけにとどめた

## 原本を読んでいて気づいた点

執筆の際に、原本の v1.3.0 に次の点を見つけました（2026年11月に確認）。本書では訂正した内容で書いています。ただし、本書の読み違いの可能性もあるので、気になる場合はコア仕様で確かめてください。

| 原本の節 | 記述 | 本書の見方 |
|---|---|---|
| §9.1.2 | 44.1 kHz で 10 ms のフレームは 4410 サンプル | 44100 × 0.01 = 441 サンプルになる |
| §9.1.1 | 3分の曲は「約 24 MB」 | 計算は合っているが、これは1チャンネル分。ステレオなら2倍になる |
| §14.4 | `AUX_CONNEXT_REQ` | `AUX_CONNECT_REQ` の誤記と思われる |
| §14.5 | `AUX_EXT_IND` | 原本の PDU の表に存在せず、`AUX_ADV_IND` のことと思われる |
| §7.8.5.3.3 | BIG の説明で「Figure 28」を参照 | 該当する図は Figure 34 と思われる |
| §3 | EDR は 2 Mb/s | EDR には 3 Mb/s のモードもある（[第21章](./ch21)） |

## コア仕様との照合

第I〜IV部の記述は、2026年11月に Core v7.0 と照合しました。原本の v1.3.0 は Core 6.0 までの内容なので、それより後の変更（HDT PHY、データ署名の廃止、セキュリティモード4など）は、照合の際に本文へ反映しました。記述ごとの照合の記録は [GitHub の review フォルダ](https://github.com/mujuko/bluetooth-the-book/tree/main/review)にあります。

本書は Bluetooth SIG とは関係のない非公式の教材です。Bluetooth® の名称とロゴは Bluetooth SIG, Inc. の登録商標です。

誤りを見つけたら、[GitHub の Issue](https://github.com/mujuko/bluetooth-the-book/issues) で教えてください。
